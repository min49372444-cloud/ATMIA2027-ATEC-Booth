ATEC Interactive Booth — Mobile panoramic preview update

1. Extract this ZIP.
2. Copy index.html, css/style.css and js/app.js into Interactive_Booth\03_Website, replacing the existing three files.
3. Do NOT delete or overwrite your existing data/content.json or assets.
4. Preview locally and then upload the same three files to your GitHub repository (commit changes).
5. Wait for GitHub Pages deployment, then refresh your phone browser.

On mobile, the booth image fills most of the screen height and scrolls horizontally with a finger swipe. Hotspots travel with the image and remain tappable. The page below the booth continues to scroll vertically.

If the image is panoramic, the phone initially shows its left side; swipe left to see the right side.
